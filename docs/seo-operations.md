| 项目 | 实现 | 验证方式 |

| 推广链接 | `rel="sponsored nofollow noopener noreferrer"`，新窗口 | 检查脚本 |

## 站外曝光（建议节奏）

1. **Telegram 频道**：每发布一篇文章，用 `docs/telegram-share.md` 的格式发一条（标题 + 两句要点 + 链接），每天不超过 1–2 条。
2. **问答与社区**：在相关问题下用自己的话回答，必要时附一篇对应文章链接；不批量发帖、不复制粘贴同一段文字。
3. **可被引用的资源**：测试方法页、测试记录模板、比较表口径说明是最可能被别人引用的页面，可以主动分享给做同类内容的作者。
4. **不做**：购买外链、站群互链、在旧站批量放链接、在不相关网站留言。这些都属于 Google 垃圾内容政策中的链接操纵。

## 数据优化（接入 Search Console 后每周一次）

1. **效果 → 查询**：找出“展示多、点击少”的查询，检查对应页面的 title/description 是否回答了这个查询。
2. **平均排名 8–20 的页面**：优先补充内容（新增小节、表格、内链），这类页面最容易进入首页。
3. **同一查询多个页面竞争**：合并或调整主题，保持“一个搜索意图一个主页面”（见 `keyword-map.csv`）。
4. **网页报告**：处理“已发现 - 尚未编入索引”“重复网页”等问题；品牌页 noindex 属于预期。
5. **记录**：每次修改写在本文件末尾的变更日志，4 周后对比点击与展示变化。

> 本站没有获得任何关键词工具或 GSC 数据，`keyword-map.csv` 中的搜索量全部留空。有数据后填写，并注明工具、地区、语言和日期。不承诺排名或流量。
