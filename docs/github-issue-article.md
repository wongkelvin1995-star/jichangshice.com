## 为什么做机场实测

买机场之前，大多数人会看三样东西：价格、速度、别人的评价。问题是，这三样东西往往来自不同的地方，口径也不一样。有的价格是年付折算成月均，有的流量是全年总量；有的测速截图只截了最好看的一次，看不出是几点测的、在哪个城市、用的什么宽带。

机场实测（也叫机场测试）想做的事情很简单：把这些资料放到同一套标准下，并且写清楚每一条是从哪里来的。能核验的就核验，核验不了的就如实标注“参考”，没有测过的就写“未测”，不估算，也不拿来排名。

## 测什么、怎么记录

一张测速截图能说明的东西其实很有限。所以每条本站记录都尽量写下：测试时间、所在城市、测速工具和服务器、出口 IP 归属，以及截图里能看到的全部数值。主要项目包括：

**延迟与抖动**：网络空闲时的往返时间和波动。延迟低说明响应快，但不代表带宽大，所以不按延迟排名。

**下载与上传速度**：多连接并发测得的平均速度。结果受本地宽带上限、测速服务器位置和节点负载影响，同一节点换个时间测也可能差很多。

**满载延迟**：下载、上传进行中的延迟。看视频、开视频会议会不会卡，这个数字往往比空载延迟更有参考价值。

**晚高峰表现**：以北京时间 20:00–23:00 为时段，和白天对照。只测一晚容易受偶然情况影响，比较可靠的做法是连续几天、同一节点、同一工具。

**丢包**：至少连续测 20 次以上再算比例。浏览器里测不了丢包，网速测试页面不会显示估算值。

**AI 与流媒体访问**：逐项记录能否打开页面、登录、完成一次对话或正常播放。网站能连上不等于账号地区可用，结果也只对当次测试的节点有效。

完整流程写在 [测试方法](https://jichangshice.com.cn/testing-methodology/)。如果想自己测，可以连上节点后打开 [网速测试](https://jichangshice.com.cn/speedtest/)，一次测出口 IP、延迟、下载上传、满载延迟和 15 个常用网站的连通性，测速在浏览器中完成，结果不上传。
