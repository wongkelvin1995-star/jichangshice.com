# 每周实测图更新流程

站长计划每周更新其他机场的实测图。每次按下面的方式提供资料，就能直接生成实测图并登记为「本站测试（已核验）」。

## 站长需要提供

每个节点 3 张截图，加上测试信息：

1. **测速完成页**：要看到「测试完成」、出口地区、测速服务器和下方的总结栏（满载延迟、质量评分）。
2. **网站连通性**。
3. **IP 信息**：地区、城市、网络、ASN。
4. 文字说明：**品牌、节点地区、测试地点、测试时间**（不确定时写「某时某分前」）。

可以用本站的「机场网速测试」（`/speedtest/`），测完点「保存测速报告图」，一张图就包含上面全部内容。

## 发布前核对（由编辑完成）

- 出口 IP 归属和测速服务器要与节点地区一致；不一致就先不发布，并在测评里如实说明。
- 截图里的出口 IP 一律打码后才放进 `public/evidence/<品牌>-<地区>-<日期>/`。
- 数值只取截图上能看到的；截图没有的写「未测」。
- 在 `src/data/test-photos.ts` 加实测图，在 `src/data/test-runs/` 加已核验记录（确切时刻未知时填 `timeNote`）。
- 品牌测评正文补一段分析，只在内容真的修改时更新 `modDatetime`。
- 构建、全站检查通过后推送 main；IndexNow 会自动通知 Bing。
