套餐介绍里常写“原生 IP”“家宽 IP”，节点名写着“美国 01”，可是打开某个网站，它却说你在另一个国家。要理解这些现象，先要分清一条连接的入口和出口，再弄清网站是怎样判断你在哪里的。

## 入口和出口

一条经过机场的连接，通常有两端：

- **入口**：你的设备先连到的服务器，多数在国内或离你较近的地方（中转线路）；
- **出口**：最终替你访问网站的服务器，它的 IP 就是网站看到的“你的 IP”。

节点名写的地区，一般指**出口**所在地区。但中间可能还有中转，入口和出口不在同一个地方很正常。延迟数字反映的是整条链路，不只是出口的距离。

## 网站怎样判断你的地区

网站一般根据**出口 IP** 查询 IP 地理数据库，得到国家和城市。问题在于：

1. **不同数据库的结果不同**：同一个 IP，在 A 数据库是美国，在 B 数据库可能是别的国家；
2. **数据库更新有延迟**：IP 段转手给另一个地区使用后，数据库可能几周甚至几个月后才更新；
3. **平台有自己的判断**：大型平台会结合自己的数据，结果可能和公开查询网站不同。

所以“节点名是美国，网站说你在别处”，多半是出口 IP 在数据库里的归属和节点名不一致。本站[灵动云测速记录](/test-records/lingdongyun/)中，台湾节点被 Netflix、Disney+ 识别为西班牙，就是这种情况。

## 原生 IP、机房 IP、家宽 IP

**机房 IP**：属于数据中心或云服务商的 IP 段。成本低、数量多，是多数机场节点的出口类型。缺点是部分平台会对这类 IP 更警惕，可能要求验证或限制功能。

**原生 IP**：通常指 IP 的注册地和使用地一致，例如在美国注册、在美国使用。它的反面是“广播 IP”：在一个国家注册、宣告到另一个国家使用。原生 IP 在地区判断上更不容易出错。

**家宽 IP**：属于家庭宽带运营商的 IP。平台通常把它当成普通用户，风控更宽松。但家宽 IP 资源少、成本高，宣传为家宽的节点，需要自己核对。

**注意**：这些都是对 IP 的分类，**不代表速度快慢，也不等于更安全**。家宽 IP 不会让你的数据更加保密，它影响的只是平台怎么看待这个 IP。

## 怎样自己核对

1. 连上节点，打开两三个不同的 IP 查询网站，看国家、城市和 ASN（运营商编号）；
2. ASN 名称里有云服务商或数据中心字样的，通常是机房 IP；
3. 对 AI 和流媒体，以平台自己的判断为准：登录后看账户地区，或看内容是否正常；
4. 记录节点名与查询结果，发现不一致时反馈给服务商。

## 对 AI、流媒体和账号的影响

- **AI 平台**：会检查出口地区是否在支持范围内，香港等地区出口可能直接不可用；部分平台对机房 IP 更容易出现验证；
- **流媒体**：片库按出口地区提供，地区判断错误会导致内容不同或无法播放；
- **账号安全**：频繁更换出口国家，可能触发异地登录验证。建议同一个账号固定使用同一个地区的节点。

## AI 和流媒体需要的地区不同时

常见的情况是：AI 平台需要日本或美国出口，视频想看香港或台湾的内容。一个节点满足不了两种需求时：

1. 在客户端里建两个策略组，分别放不同地区的节点；
2. 用分流规则把 AI 域名和视频域名分到各自的组；
3. 每个组固定一个节点，避免自动切换导致账号地区变化。

配置方法见[分流规则排查](/troubleshooting/split-routing-issues/)。

## 常见疑问

### 节点名写美国，网站说我在别的国家，是机场骗人吗？

不一定。可能是 IP 数据库归属不一致，或出口 IP 本身是广播 IP。用多个网站查询，以你要访问的平台判断为准。

### 原生 IP 一定能用 AI 吗？

不一定。还要看出口地区是否在平台支持范围内，以及平台对该 IP 段的判断。

### 家宽 IP 更安全吗？

安全性主要取决于加密和服务商管理，和 IP 类型无关。家宽 IP 主要影响平台风控的宽松程度。

### 怎么看一个 IP 是不是机房 IP？

看 IP 查询结果中的 ASN 和组织名称，属于云服务商或数据中心的，通常是机房 IP。
