机场套餐介绍里经常同时出现“IPLC 专线”“BGP 中转”“VLESS 协议”这样的词，看起来都是技术优势，但它们描述的是完全不同的东西。弄清楚各自属于哪一层，才能读懂宣传，也知道哪些说法需要自己验证。

## 先分清两层：线路和协议

可以把一次代理连接想成“寄快递”：

- **线路**是快递走的路：走高速还是国道，中途在哪里转运。IPLC、IEPL、BGP、中转、直连都属于这一层。
- **协议**是包裹的打包方式：用什么箱子、怎么封口、贴什么标签。VLESS、Trojan、Shadowsocks、Hysteria2 都属于这一层。

同一条线路上可以跑不同的协议，同一个协议也可以跑在不同的线路上。所以“VLESS 线路”这种说法其实混淆了两层，本站整理品牌资料时会把线路和协议分成两个字段。

## 线路相关的词

### 直连

你的设备直接连接位于境外的节点服务器，数据经过运营商的公共国际出口。优点是简单、成本低；缺点是受公共出口拥堵影响，晚高峰表现波动大。

### 中转

先连接一台位于境内或靠近境内的中转服务器，再由中转服务器把数据转发到境外的落地服务器。中转的目的通常是改善线路质量或路由，但多了一跳，也多了一个可能出问题的环节。

### BGP

BGP（边界网关协议）本身是互联网上用来交换路由的协议。在机场语境里，“BGP 中转”“BGP 入口”通常指入口服务器接入了多家运营商的网络，不同运营商的用户可以就近接入，减少跨运营商绕路。它描述的是**入口的接入方式**，不代表跨境那一段走的是专线。

### IPLC 与 IEPL

两者都是运营商提供的跨境专用线路产品：

- **IPLC**（国际私用租用电路）：点对点的专用电路；
- **IEPL**（国际以太网专线）：基于以太网的点对点专线。

对用户来说，两者的共同点是：跨境那一段不走公共国际出口，理论上受公共出口晚高峰拥堵的影响较小。但要注意：

1. 专线只覆盖“入口到出口”这一段。你家到入口服务器、出口到目标网站这两段，仍然是普通网络。
2. 专线带宽成本高，机场是否买够了带宽、用户是否过多，从宣传上看不出来。
3. “专线”的说法很难由用户直接验证。本站整理资料时只记录为“资料中提到”，不作为测试结论。

## 协议相关的词

| 协议 | 简要说明 |
|---|---|
| Shadowsocks | 较早出现的轻量加密代理协议，客户端支持面最广 |
| Trojan | 把代理流量伪装成常见的 HTTPS 流量 |
| VLESS | 轻量协议，常与 TLS、Reality 等传输层技术配合使用 |
| Hysteria2 | 基于 QUIC（UDP）的协议，强调在丢包网络中的传输效率 |

协议影响的是**客户端能不能用**以及一定程度上的性能和抗干扰表现。实际中更常见的问题是兼容性：只支持原版 Clash 内核的旧客户端不支持 VLESS、Hysteria2，导入后会出现节点缺失。不能只凭“支持 VLESS”就认为任意 Clash 版本都能直接导入，详见[Clash 订阅导入教程](/clients/clash-subscription-import/)。

## 读宣传时怎么判断

| 宣传说法 | 它描述的是 | 需要自己确认 |
|---|---|---|
| “全 IPLC 专线” | 跨境段的线路类型 | 是全部节点还是部分节点；晚高峰实际表现 |
| “BGP 入口” | 入口接入方式 | 你的运营商连入口是否顺畅 |
| “支持 VLESS / Hysteria2” | 协议 | 你的客户端是否支持 |
| “原生 IP” | 出口 IP 的归属类型 | 具体服务是否认可，需按服务实测 |
| “解锁流媒体” | 出口 IP 能否访问某服务 | 具体节点、具体操作，见[AI 与流媒体测试](/methods/ai-streaming-checks/) |

线路类型能帮你理解一个机场的成本结构和设计思路，但不能代替测试。同样标注 IPLC 的两家机场，晚上的体验可能完全不同；这和你所在的地区、运营商关系很大，见[节点地区、运营商与本地网络为什么影响结果](/routes/node-region-isp/)。

## 常见疑问

### 专线节点一定比直连快吗？

不一定。专线主要改善的是跨境段在拥堵时段的表现；如果直连线路在你的运营商下本来就通畅，白天的差别可能不大。最终以自己在常用时段的体验为准。

### 原生 IP 和住宅 IP 是一回事吗？

不完全是。“原生 IP”通常指 IP 归属地与节点所在地一致；“住宅 IP”指分配给家庭宽带用户的 IP，与机房 IP 相对。不同服务对这些 IP 类型的判断标准不公开，宣传说法需要按具体服务实际检查。
