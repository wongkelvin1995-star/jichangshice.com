常见的情况是：同一个节点，ChatGPT 能正常对话，切到 Claude 却提示所在地区不支持；或者 Gemini 网页能用，调用 API 时报地区错误。这不是节点“坏了”，而是**不同 AI 平台的地区政策和风控规则不一样**。下面按顺序排查。

## 为什么同一个节点结果不同

1. **支持的地区列表不同**：OpenAI、Anthropic、Google 各自公布支持的国家和地区，列表并不相同，以官方页面为准：[ChatGPT](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)、[Claude](https://www.anthropic.com/supported-countries)、[Gemini](https://support.google.com/gemini/answer/13575153)；
2. **对 IP 的判断不同**：同一个出口 IP，各平台使用的地理数据库和风控规则不同，可能一个判定为美国，另一个判定为别的地区；
3. **网页和 API 是两套检查**：网页版可用，不代表 API 也可用，反之亦然。

## 第 1 步：确认节点出口地区

- 连上节点，打开两三个 IP 查询网站，看国家和城市；
- 对照该 AI 平台的支持地区列表；
- 出口在不支持的地区（例如部分平台不支持香港），换到支持地区的节点。

出口 IP 的判定原理见[入口与出口 IP、原生 IP 与机房 IP](/routes/exit-ip-native-ip/)。

## 第 2 步：确认账号地区

部分平台会记录账号注册或付款时的地区：

- 账号注册地区和当前登录地区差别很大时，可能需要额外验证；
- 付费订阅的账单地区也可能影响可用性；
- 同一个账号频繁在不同国家之间切换，容易触发风控。

**处理**：选一个支持的地区（如日本或美国），以后都用这个地区的节点登录这个账号。

## 第 3 步：IP 类型与共享情况

- 机场节点多为机房 IP，部分平台对机房 IP 更容易要求验证；
- 一个节点同时被很多用户使用，平台可能检测到大量请求来自同一 IP；
- 表现为频繁出现人机验证、登录循环或“请求过多”。

**处理**：换同地区的其他节点；仍频繁出现时，向机场客服说明是哪个平台、哪个节点。

## 第 4 步：浏览器环境

- **清除该平台的 Cookie 和缓存**，或用无痕窗口测试；
- **浏览器语言和时区**：和节点地区差别很大时，个别平台会更谨慎，可以先排除其他原因再考虑；
- **插件**：关闭代理切换类、翻译类插件后再试；
- **DNS 与分流**：确认平台相关的所有域名都走了同一个节点，否则登录过程中可能“一半在日本、一半直连”。见[分流规则排查](/troubleshooting/split-routing-issues/)。

## 第 5 步：区分网络限制和账号限制

| 现象 | 更可能是 |
|---|---|
| 未登录就提示地区不支持 | 网络（出口地区） |
| 换支持地区的节点后恢复 | 网络 |
| 任何节点都提示账号受限 | 账号 |
| 登录后提示需要验证身份 | 账号或 IP 风控 |
| 无痕窗口正常、普通窗口异常 | 浏览器缓存 |

账号问题需要通过平台官方渠道处理，换节点解决不了。

## API 的额外检查

开发者调用 API 时：

1. 确认终端或程序真的走了代理（环境变量 HTTPS_PROXY 或客户端 TUN 模式）；
2. 确认请求的出口地区在该平台 API 的支持范围内；
3. 看返回的错误信息：地区错误、鉴权错误、额度错误是三类不同的问题。

## 排查时记下这些信息

无论最后是联系机场客服，还是联系 AI 平台，下面这些信息都能节省时间：

- 时间（精确到分钟）和使用的节点名；
- 出口 IP 查询到的国家和城市；
- 平台显示的完整错误信息（截图时遮挡账号）；
- 换节点、无痕窗口之后的结果。

**找机场客服**：同一地区的多个节点都提示地区不支持，或 IP 被识别到了错误地区。

**找 AI 平台**：换了支持地区的节点、清除缓存后，账号仍然显示受限或需要验证。

## 固定使用的建议

确认可用以后：

1. 选一个支持地区作为该账号的固定地区；
2. 在客户端里把该平台的域名分到只含这个地区节点的策略组；
3. 节点维护时，切换到同地区的其他节点，而不是换国家。

## 常见疑问

### 为什么 ChatGPT 能用，Claude 不能用？

两个平台支持的地区和风控规则不同。换一个在 Claude 支持范围内的地区节点再试。

### 换了节点还是提示地区不支持？

清除浏览器缓存或用无痕窗口；确认平台的所有域名都走了新节点。

### 频繁换节点会不会被封号？

频繁在不同国家之间切换会增加风控概率，建议固定一个支持地区。

### 香港节点能用 Claude 吗？

以 Anthropic 官方支持地区为准；本站档案中多家机场的香港节点连 ChatGPT 都不可用，建议直接用日本、美国等地区。
