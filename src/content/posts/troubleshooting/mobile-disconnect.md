在电脑上一切正常，到了手机上却经常断：出门时 Wi-Fi 切到 4G，代理要过一阵才恢复；锁屏一会儿，再打开时客户端已经断开。这些问题大多和手机的网络切换、省电策略有关，而不是机场本身的问题。

## 为什么切网会断

手机从 Wi-Fi 切到移动数据时，**本机 IP 地址会变**。所有正在进行的连接都建立在旧地址上，切换后这些连接会失效，客户端需要重新建立到节点的连接。这个过程中：

- 正在加载的网页、视频会中断；
- 客户端检测网络变化、重新连接需要几秒；
- 如果当前节点延迟高，重连会更慢。

在地铁、电梯里信号反复变化时，这种重连可能频繁发生。

## Android 的设置

1. **关闭电池优化**：设置 → 应用 → 找到代理客户端 → 电池 → 选“不受限制”或“无限制”。不同品牌手机的菜单名称不同；
2. **允许后台运行和自启动**：部分国产系统有单独的“自启动管理”“后台运行管理”，需要手动允许；
3. **锁定后台**：在多任务界面把客户端锁定，防止一键清理时被关掉；
4. **始终开启 VPN**：设置 → 网络 → VPN → 客户端旁的设置，开启“始终开启的 VPN”。注意不要同时开启“屏蔽未使用 VPN 的连接”，否则客户端断开时会完全无法上网；
5. **客户端内设置**：部分 Clash 系客户端有“网络变化时重新连接”或类似选项，打开它。

## iOS 的设置

1. **按需连接**：Shadowrocket 等客户端支持“按需连接”，网络变化时自动重新连接；
2. **允许后台刷新**：设置 → 通用 → 后台 App 刷新，确保客户端开启；
3. **关闭低电量模式**：低电量模式会限制后台活动；
4. **定期检查 VPN 配置**：设置 → VPN，确认配置状态正常，系统更新后偶尔需要重新允许。

## 节点选择也有影响

- **移动网络下选低延迟节点**：重连时间和延迟有关，香港等近距离节点恢复更快；
- **固定节点，避免自动选择频繁切换**：自动选择会在网络变化后重新测速，可能切到不同节点，导致登录状态变化；
- **注意倍率**：移动数据下看视频更费流量，倍率节点消耗更快。

## 常见现象与处理

| 现象 | 处理 |
|---|---|
| 切网后几秒恢复 | 正常现象，可开启自动重连缩短时间 |
| 切网后一直不恢复 | 手动切换一次节点，或关闭再打开连接 |
| 锁屏后客户端断开 | 关闭电池优化，允许后台运行 |
| 只有移动数据下连不上 | 部分运营商网络对某些端口有限制，换节点或换协议 |
| 断开时完全无法上网 | 检查是否开启了“屏蔽未使用 VPN 的连接” |

## 移动数据下省流量

手机用移动数据时，流量消耗来自两部分：机场套餐流量和手机运营商流量。可以这样节省：

- **规则模式而不是全局**：国内网站直连，不消耗机场流量；
- **视频降清晰度**：移动网络下选 720p 或自动；
- **关闭后台自动更新**：应用商店、云相册的自动同步改为仅 Wi-Fi；
- **避开高倍率节点**：节点名带倍率标注的，扣得更快；
- **定期看面板用量**：月中检查一次，避免月底超量。

## 流量和隐私

- 手机和电脑共用一个订阅时，各自占用设备名额，流量合并计算；
- 不要在公共场合截图客户端界面，订阅链接和节点信息可能被看到；
- 换手机前，在旧手机上删除订阅，必要时在面板重置订阅链接。

导入步骤见[Android 与 iOS 导入机场订阅的差异](/clients/android-ios-import/)。

## 常见疑问

### 手机切网断线是机场的问题吗？

多数不是。切网会让本机 IP 变化，所有连接都需要重建，这是网络切换的正常结果。

### 为什么锁屏一会儿代理就断了？

手机的省电策略关闭了后台的客户端。按上面的设置关闭电池优化、允许后台运行。

### 移动数据下连不上，Wi-Fi 下正常？

可能是运营商网络对某些端口或协议有限制。换一个节点或换协议试试，仍不行时联系服务商。

### 手机上要不要开“始终开启的 VPN”？

可以开，能在系统重启后自动连接；但不要同时开“屏蔽未使用 VPN 的连接”，否则客户端异常时会完全断网。
