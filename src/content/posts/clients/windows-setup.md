这篇文章写给第一次在 Windows 上使用机场的读者：从选客户端、安装、导入订阅，到开启代理、确认生效，最后整理几种常见的“连上了但用不了”的情况。界面截图会随版本变化，下文以文字描述关键步骤。

## 选择客户端

Windows 上常用的两类客户端：

| 客户端 | 内核 | 适合 | 官方发布页 |
|---|---|---|---|
| Clash Verge Rev | Mihomo | 机场提供 Clash 订阅，希望用规则分流 | [GitHub Releases](https://github.com/clash-verge-rev/clash-verge-rev/releases) |
| v2rayN | Xray、sing-box 等 | 机场提供通用订阅或 v2rayN 订阅 | [GitHub Releases](https://github.com/2dust/v2rayN/releases) |

根据机场后台提供的订阅类型来选：有 Clash 订阅优先用 Clash Verge Rev；只有通用订阅可以用 v2rayN。截至 2026 年 10 月，Clash Verge Rev 最新版 v2.5.2 已不支持 Windows 7；v2rayN 的版本更新较频繁，系统要求以其 Wiki 中的“发布文件介绍”为准。

**只从上面的官方发布页下载。**搜索引擎里常有仿冒下载站，安装包可能被篡改。

## 安装 Clash Verge Rev

1. 打开官方发布页，在最新正式版（标记为 Latest）的 Assets 列表中，找到 Windows 安装包。大多数电脑选 x64 版本；ARM 处理器的设备选 arm64 版本。
2. 运行安装程序，按提示完成安装。系统如果提示缺少 WebView2，可以选择附带 WebView2 的安装包，或先安装 WebView2 运行时。
3. 首次启动后，Windows 防火墙可能弹窗询问网络访问权限，允许即可。

## 导入订阅并开启代理

1. 在机场后台复制 **Clash 格式**的订阅链接。
2. 打开 Clash Verge Rev → “订阅” → 粘贴链接 → “导入”。
3. 点击导入后的订阅卡片使其生效。
4. 进入“代理”页面，选择节点组中的一个节点，点击测速按钮查看延迟。
5. 进入“设置”，打开“系统代理”。
6. 打开浏览器访问一个常用网站，确认能正常加载。

代理模式建议保持“规则”。全局模式会让所有流量走代理，国内网站变慢，也更耗流量。导入前要核对的细节见[Clash 订阅导入教程](/clients/clash-subscription-import/)。

## 系统代理和 TUN 模式有什么区别

| | 系统代理 | TUN（虚拟网卡）模式 |
|---|---|---|
| 原理 | 在 Windows 代理设置中写入本地代理地址，遵守这个设置的程序才会走代理 | 创建虚拟网卡，接管系统层面的网络流量 |
| 覆盖范围 | 浏览器和大部分常用软件 | 包括不读取系统代理设置的程序（如部分命令行工具、游戏） |
| 设置难度 | 打开开关即可 | 需要安装服务或管理员权限 |
| 常见问题 | 部分软件不走代理 | 与其他 VPN、加速器冲突 |

一般浏览网页、用 AI 工具，系统代理就够了。只有某个程序不走代理时，再考虑开启 TUN 模式。开启 TUN 前，先关闭其他 VPN 或加速器软件。

## 常见连接问题

### 已开启系统代理，浏览器还是打不开

- 检查是否有其他代理软件（旧客户端、加速器、浏览器代理插件）同时运行，它们会覆盖系统代理设置；
- 在 Windows“设置 → 网络和 Internet → 代理”中查看“使用代理服务器”是否开启，地址是否是客户端显示的本地端口；
- 浏览器如果装了代理插件，先停用插件再试。

### 节点全部超时

先换一个网络（例如手机热点）试试，排除本地网络问题；再确认电脑系统时间是否准确，时间偏差过大会导致部分协议握手失败。完整步骤见[订阅更新失败与节点全部超时的排查路径](/troubleshooting/subscription-update-failed/)。

### 关闭客户端后上不了网

客户端非正常退出时，系统代理设置可能没被清除。重新打开客户端再正常关闭，或者到 Windows 代理设置中手动关闭“使用代理服务器”。

### 国内网站也变慢

检查是否误开了全局模式；在规则模式下，国内网站应当直连。

## 使用 v2rayN 的简要步骤

1. 从官方发布页下载 Windows 版压缩包，解压到固定目录后运行。
2. 在“订阅分组”中添加订阅地址，然后执行“更新订阅”。
3. 在服务器列表中选择节点，设为活动服务器。
4. 在主界面底部或托盘菜单中设置系统代理。

菜单名称会随版本调整，以实际界面为准。

## 常见疑问

### 杀毒软件报毒怎么办？

代理客户端会修改系统代理、创建虚拟网卡，部分安全软件会误报。先确认安装包来自官方发布页，必要时用发布页提供的校验信息核对文件；无法确认来源的安装包不要运行。

### 可以和公司 VPN 一起用吗？

两者可能互相覆盖路由和代理设置。需要访问公司内网时，建议先关闭机场客户端，或者只使用系统代理而不开 TUN。
