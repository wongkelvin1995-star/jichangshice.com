“订阅导入不了”“导入了但节点全是超时”是 Clash 类客户端最常见的两个问题。大多数情况不是机场坏了，而是导入前有几件事没对上：订阅格式、客户端内核、链接是否完整。这篇文章先理清 Clash 相关名词，再给出导入前的核对清单和导入后的检查步骤。

## 先理清几个名字

“Clash”现在通常指一类客户端，而不是某一个软件：

- **Clash / Clash Premium**：最早的内核项目，原项目已停止维护。
- **Mihomo（原 Clash Meta）**：在 Clash 基础上继续开发的内核，支持 VLESS、Hysteria2 等更多协议，是目前多数 Clash 类客户端使用的内核。
- **客户端（图形界面）**：如 Clash Verge Rev（Windows、macOS、Linux）、FlClash（Windows、macOS、Linux、Android）等。它们负责管理订阅和设置，实际转发流量的是里面的内核。

所以判断“这个客户端能不能用某个协议”，要看它**用的是哪个内核、内核是什么版本**。截至 2026 年 10 月，Clash Verge Rev 在 GitHub 发布页的最新版本是 v2.5.2，内置的 Mihomo 内核为 v1.19.29；版本会持续更新，以[官方发布页](https://github.com/clash-verge-rev/clash-verge-rev/releases)为准。

## 导入前核对五件事

### 1. 订阅格式对不对

机场后台通常提供多种订阅链接，例如“Clash 订阅”“通用订阅”“sing-box 订阅”。Clash 类客户端需要的是 **Clash/Mihomo 格式**（内容是 YAML 配置）。把通用订阅（Base64 编码的节点列表）直接填进去，常见结果是导入失败或节点为空。

部分机场的订阅会根据客户端自动返回对应格式，但不是所有机场都这样做，优先使用后台明确标注“Clash”的那一条。

### 2. 协议客户端是否支持

如果机场节点使用 VLESS、Hysteria2 等较新的协议，客户端必须使用支持这些协议的内核。只用原版 Clash 内核的旧客户端，导入后会出现节点缺失或报错。不要只凭机场写着“支持 VLESS”，就认为任何 Clash 客户端都能直接用。

### 3. 链接是否完整

复制订阅链接时容易漏掉末尾字符，或者多复制了空格、换行。导入前检查：

- 链接以 `https://` 开头；
- 末尾的参数（通常是 `token=` 后面一长串字符）完整；
- 没有被聊天软件自动截断或加上其他文字。

示例格式：`https://sub.example.com/api/v1/client/subscribe?token=xxxxxxxx`（此为示例地址）。

### 4. 账号是否正常

账号到期、流量用完、订阅被重置后，旧链接可能返回空内容或错误。导入前先登录机场后台看一眼账号状态。

### 5. 客户端版本是否过旧

旧版本客户端可能不支持新的配置字段。先更新到官方发布页的最新正式版，再导入。

## 导入步骤（以 Clash Verge Rev 为例）

不同版本的菜单文字可能略有差异，核心步骤相同：

1. 打开客户端，进入“订阅”页面。
2. 在输入框粘贴 Clash 格式的订阅链接，点击“导入”。
3. 导入成功后，订阅卡片会显示名称、流量和到期信息（取决于机场是否提供）。
4. 点击该订阅卡片，使其处于选中（当前使用）状态。
5. 进入“代理”页面，选择一个节点，对节点组做一次延迟测试。
6. 在设置中开启“系统代理”，用浏览器打开一个网站检查。

FlClash 等其他客户端的流程类似：添加配置（选择 URL 方式）→ 粘贴订阅 → 选中配置 → 选择节点 → 开启代理。

## 导入后检查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 提示导入失败 | 格式不对、链接不完整、网络无法访问订阅地址 | 换 Clash 格式链接；检查链接；换网络后重试 |
| 导入成功但节点为空 | 订阅格式不匹配，或账号已到期 | 检查后台账号状态与链接类型 |
| 节点全部超时 | 本地网络、系统时间、测试地址或节点问题 | 见[订阅更新失败与节点全部超时](/troubleshooting/subscription-update-failed/) |
| 延迟正常但网页打不开 | 系统代理未开启或被其他软件占用 | 检查系统代理与其他代理软件 |

## 常见疑问

### 可以同时导入多个机场的订阅吗？

可以导入多个，但同一时间通常只有一个配置处于生效状态。需要切换时，在订阅列表中点选另一个即可。

### 订阅多久更新一次？

机场调整节点后需要更新订阅才能看到变化。多数客户端可以设置自动更新间隔，一般设为每天一次即可，太频繁可能被机场限制访问。

## 安全提醒

- 订阅链接等同于账号凭证，不要截图分享；
- 只从客户端官方发布页下载安装包，不使用来路不明的“破解版”“整合版”；
- 怀疑泄露，到机场后台重置订阅链接。
