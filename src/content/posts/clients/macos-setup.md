macOS 上使用机场的流程和 Windows 类似，多出来的主要是两件事：按芯片选择正确的安装包，以及处理系统的安全和权限提示。这篇文章按“下载 → 安装 → 授权 → 导入 → 检查”的顺序写。

## 第一步：确认你的 Mac 用的是什么芯片

点击屏幕左上角苹果菜单 →“关于本机”：

- 显示“芯片 Apple M1/M2/M3/M4…”：选择 **aarch64 / arm64** 版本；
- 显示“处理器 Intel…”：选择 **x64 / x86_64 / amd64** 版本。

装错版本，轻则运行缓慢，重则无法打开。

## 第二步：选择并下载客户端

| 客户端 | 说明 | 官方发布页 |
|---|---|---|
| Clash Verge Rev | Mihomo 内核，功能完整，支持规则分流与 TUN | [GitHub Releases](https://github.com/clash-verge-rev/clash-verge-rev/releases) |
| FlClash | Mihomo 内核，界面简洁，同时有 Android 版 | [GitHub Releases](https://github.com/chen08209/FlClash/releases) |

两者都使用 Clash/Mihomo 格式的订阅。截至 2026 年 10 月，Clash Verge Rev 最新版为 v2.5.2，FlClash 最新版为 v0.8.99，均提供 Apple 芯片和 Intel 芯片的 .dmg 安装包。请以发布页为准，不要从来历不明的网盘下载。

## 第三步：安装与首次打开

1. 双击下载的 .dmg 文件，把应用拖到“应用程序”文件夹。
2. 首次打开时，macOS 可能提示“无法验证开发者”或“无法打开”。这是因为应用没有通过苹果的公证分发：
   - 打开“系统设置 → 隐私与安全性”，在页面下方找到被阻止的应用，点击“仍要打开”；
   - 再次打开应用，确认即可。
3. 如果提示“已损坏，无法打开”，先确认下载的是对应芯片的官方安装包，并重新下载一次。不要随意执行网上流传的命令去关闭系统安全功能。

## 第四步：授权

客户端可能会请求以下权限：

- **网络扩展 / 系统代理**：修改系统代理设置时需要输入 Mac 登录密码；
- **TUN 模式所需的服务或辅助程序**：只有开启 TUN 时才需要，安装时会请求管理员授权。

只授予你计划使用的功能所需的权限。日常使用系统代理即可，不必一开始就开启 TUN。

## 常见疑问

### Apple 芯片的 Mac 能不能装 Intel 版本？

能通过 Rosetta 转译运行，但效率更低，也更容易遇到权限组件不兼容的问题。官方同时提供两种版本时，直接选与芯片对应的版本。

### 系统代理和“网络扩展”有什么不同？

系统代理只是在 macOS 网络设置里写入一个本地代理地址，遵守这个设置的应用才会走代理；TUN 一类的模式会接管更底层的网络流量，覆盖范围更广，但需要额外授权，也更容易与其他 VPN 工具冲突。日常先用系统代理，遇到个别应用不走代理时再考虑 TUN。

### 公司电脑可以装吗？

公司设备通常装有管理软件或安全策略，安装代理客户端可能违反公司规定，也可能与公司的网络配置冲突。请先确认所在单位的规定。

### 需要开机自启吗？

看个人习惯。开启后每次开机自动连接，省去手动操作；但如果经常需要直连（例如访问公司内网），可以保持手动启动，避免忘记关闭代理。

## 第五步：导入订阅

1. 在机场后台复制 Clash 格式订阅链接。
2. Clash Verge Rev：“订阅” → 粘贴 → “导入” → 点击订阅卡片使其生效。
   FlClash：进入配置页 → 添加 → 选择通过 URL 添加 → 粘贴 → 保存并选中。
3. 在代理页面选择节点，做一次延迟测试。
4. 开启“系统代理”，保持“规则”模式。
5. 用 Safari 或 Chrome 打开一个常用网站检查。

导入失败时，先看[Clash 订阅导入教程](/clients/clash-subscription-import/)里的五项核对。

## macOS 常见问题

### 系统代理已开，Safari 能用但某个应用不行

部分应用不读取系统代理设置。可以在该应用内单独设置代理（填客户端显示的本地地址和端口），或者开启 TUN 模式。

### 和其他 VPN 或网络工具冲突

同时运行多个代理或 VPN 工具时，后开启的往往会覆盖前一个的设置。检查“系统设置 → 网络”中是否有其他 VPN 配置处于连接状态，先断开再试。

### 合上盖子再打开后连不上

睡眠唤醒后网络切换，可能导致连接中断。在客户端里切换一次节点或重新开关系统代理，通常可以恢复。

### 节点全部超时

先检查系统时间是否设为“自动设置”，再换网络测试，完整排查见[订阅更新失败与节点全部超时](/troubleshooting/subscription-update-failed/)。

## 卸载时要注意

卸载客户端前，先在客户端中关闭系统代理和 TUN，再退出应用、删除应用。否则系统代理设置可能残留，导致卸载后无法上网；如已出现，在“系统设置 → 网络 → 当前网络 → 详细信息 → 代理”中关闭相应选项即可。
