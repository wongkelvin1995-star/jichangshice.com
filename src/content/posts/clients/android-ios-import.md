同一个机场订阅，在 Android 和 iPhone 上的使用方式差别不小：客户端从哪里获取、支持什么订阅格式、能不能在后台一直运行，都不一样。这篇文章把两个系统分开讲，最后对比常见问题。

## 先看差异总览

| 对比项 | Android | iOS / iPadOS |
|---|---|---|
| 客户端获取 | 从开源项目发布页下载 APK 安装 | 通过 App Store 下载，通常需要非中国大陆地区的 Apple ID |
| 常见客户端 | FlClash、Clash Meta for Android、v2rayNG 等 | Shadowrocket、Stash、sing-box 等（多为付费或订阅制） |
| 订阅格式 | 视客户端：Clash/Mihomo 格式或通用订阅 | 视客户端：多数支持通用订阅，部分支持 Clash 格式 |
| 系统授权 | 首次连接时同意创建 VPN 连接 | 首次连接时允许添加 VPN 配置 |
| 后台运行 | 受省电策略影响较大，需要手动放行 | 系统管理较统一，一般无需额外设置 |

## Android：选择与安装

Android 客户端多数是开源项目，从 GitHub 发布页下载 APK：

- **FlClash**：Mihomo 内核，使用 Clash 格式订阅，[发布页](https://github.com/chen08209/FlClash/releases)。截至 2026 年 10 月最新版为 v0.8.99。
- **v2rayNG**：v2rayN 的移动版本，使用通用订阅。
- **Clash Meta for Android**：Mihomo 内核的 Android 客户端，使用 Clash 格式订阅。

选择 APK 时注意处理器架构：多数手机选 **arm64-v8a**；较老的 32 位设备选 armeabi-v7a。安装时系统会提示“允许安装未知来源应用”，只对你下载安装包所用的浏览器或文件管理器临时开启即可。

### Android 导入步骤（以 FlClash 为例）

1. 打开应用，进入配置页，点击添加，选择通过 URL 添加。
2. 粘贴 Clash 格式订阅链接，保存。
3. 选中这个配置，进入代理页面选择节点。
4. 点击启动，系统弹出“连接请求”时选择允许。
5. 打开浏览器检查是否能正常访问。

### Android 后台被杀怎么办

国产系统的省电策略常会在锁屏后结束客户端，表现为“过一会儿就断了”。处理方法：

- 在系统设置的电池管理中，把客户端设为“不限制”或“允许后台运行”；
- 在最近任务中锁定客户端；
- 部分系统需要同时允许“自启动”。

不同品牌手机的菜单名称不同，可以在系统设置中搜索“电池优化”或“后台运行”。

## iOS：选择与导入

iOS 上的代理类客户端通常在中国大陆地区 App Store 无法下载，需要使用其他地区的 Apple ID。常见的有 Shadowrocket、Stash、sing-box 等，多数需要付费购买或订阅。请只在 App Store 正规购买，不要使用“共享账号”下载，这类账号存在被盗用和锁机的风险。

### iOS 导入步骤（通用流程）

1. 在机场后台查看是否提供对应客户端的订阅或“一键导入”按钮，优先使用对应格式。
2. 打开客户端，在添加订阅或配置的位置粘贴订阅链接。
3. 更新订阅后选择节点。
4. 首次连接时，系统会提示“添加 VPN 配置”，允许并验证面容或密码。
5. 在 Safari 中打开网站检查。

不同客户端支持的订阅格式不同：有的直接支持 Clash 配置，有的只支持通用订阅或自有格式。导入后节点为空时，先换一种订阅格式再试。

## 两个系统共同的注意事项

- **订阅链接保密**：不要在聊天软件里转发给别人，也不要截图分享。
- **规则模式优先**：国内应用直连，节省流量，也避免部分国内应用异常。
- **设备数限制**：手机和电脑同时在线会占用设备数，超出机场限制可能无法连接，见[购买前核对的条款](/guides/check-before-buying/)。
- **更新订阅**：机场调整节点后需要在客户端里更新订阅，可设置自动更新间隔。

## 常见疑问

### 手机和电脑能用同一个订阅吗？

可以，同一个订阅链接可以导入多台设备，但会占用机场限制的在线设备数。不同客户端需要的订阅格式可能不同，手机上要选对应客户端的格式。

### 用移动数据时需要注意什么？

规则模式下国内应用直连，不额外消耗机场流量；但通过代理的流量同时会消耗手机套餐流量和机场流量，看视频前留意两边的余量。

## 问题速查

| 现象 | Android 先查 | iOS 先查 |
|---|---|---|
| 锁屏后断开 | 电池优化、后台运行权限 | 一般较少出现，检查是否开启了低电量模式 |
| 导入后节点为空 | 订阅格式是否与客户端匹配 | 同左，尝试对应客户端的订阅链接 |
| 连接成功但打不开网页 | 是否有其他 VPN 应用在运行 | 设置中的 VPN 配置是否有多个处于启用状态 |
| 更新订阅失败 | 先断开代理再更新，或换网络 | 同左 |

更详细的排查顺序见[订阅更新失败与节点全部超时的排查路径](/troubleshooting/subscription-update-failed/)。电脑端设置请看[Clash 订阅导入教程](/clients/clash-subscription-import/)。
