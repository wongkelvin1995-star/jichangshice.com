## 一翻云适合新手吗

一翻云（1fly）在本站目录中排第 20 位（编辑顺序）。品牌资料显示 2024 年起运营，**没有自研客户端**，只支持导入通用订阅，协议为 VLESS / Shadowsocks，入门档 ¥20/月、150GB、3 台设备。没有自研客户端意味着第一次使用时，要自己装客户端、导入订阅，这正是很多新手卡住的地方，所以本页重点讲首次安装。

## 订阅链接是什么

订阅链接是一串以 https 开头的网址，客户端定期访问它，下载节点列表。需要知道三点：

1. **它相当于账号密码**，别人拿到就能用你的流量，不要分享、截图要打码；
2. **格式要匹配客户端**：面板通常提供“Clash 订阅”“通用订阅”等多个按钮。Clash 系客户端用 Clash 格式（YAML 配置），v2rayNG、Shadowrocket 用通用格式（Base64 编码的节点列表）；
3. **可以重置**：泄露后在面板重置，旧链接会立即失效。

## 首次安装步骤（以 Windows 为例）

1. 从 Clash Verge Rev 的官方发布页下载安装包，不要用来路不明的打包版本；
2. 安装后打开，进入“订阅”页，粘贴 Clash 格式的订阅链接，点导入；
3. 进入“代理”页，选择一个香港或日本节点；
4. 打开“系统代理”开关，浏览器访问一个境外网站确认可用。

macOS、安卓、iOS 的步骤见 [macOS 设置](/clients/macos-setup/)和[手机端导入](/clients/android-ios-import/)。

## 系统代理和 TUN 有什么区别

| | 系统代理 | TUN 模式 |
|---|---|---|
| 原理 | 告诉系统“请把网页流量交给代理端口” | 创建一张虚拟网卡，接管所有流量 |
| 覆盖范围 | 浏览器和遵守系统代理的软件 | 几乎所有程序，包括命令行和游戏 |
| 需要权限 | 不需要 | 需要管理员权限或安装服务 |
| 适合 | 日常上网 | 软件不走代理、终端工具、游戏 |

**建议**：新手先用系统代理；遇到某个软件不走代理，再开 TUN。两者都开时，以 TUN 为准。

## 常见问题

### 一翻云要装什么客户端？

没有自研客户端。电脑用 Clash Verge Rev，安卓用 Clash 系或 v2rayNG，iOS 用 Shadowrocket 等，导入对应格式的订阅即可。

### 开了系统代理，有个软件还是不走代理怎么办？

开启 TUN 模式。部分软件不读取系统代理设置，只有 TUN 能接管它们的流量。

### 订阅链接泄露了怎么办？

在面板重置订阅链接，然后在所有设备上重新导入。
