## 节点命名重复的问题

2026-08-11 18:57 的公开测速快照中，**香港 03 在节点列表里出现了两次**，来源按原样记录，没有合并。完整数据见[Sogo云测速记录](/test-records/sogoyun/)。

重复命名会带来几个实际问题：

- **测速时混淆**：两个同名节点的结果不同，你不知道哪个是哪个；
- **自动选择失效**：客户端按名称记忆选择时，可能在两个节点之间来回切换；
- **反馈问题困难**：告诉客服“香港 03 很慢”，客服无法定位是哪一个。

## 节点名与实际出口地区可能不同

节点名称是服务商写的标签，**不等于出口 IP 的真实位置**。常见情况：

- 名为“香港”的节点，出口 IP 在其他地区；
- 名为“美国”的节点，被某些网站识别为别的国家；
- 同一个名称的节点，入口在国内、出口在境外，延迟数字反映的是入口到出口的整条链路。

**核对方法**：

1. 连上节点后，打开 IP 查询网站（如 ip.sb、ipinfo.io），看显示的国家和城市；
2. 对比节点名称，记录不一致的节点；
3. 对 AI 和流媒体，用平台自己的地区显示（比如账户设置里的地区）为准；
4. 发现重复或错位的节点时，用“节点名 + 出口 IP 地区 + 时间”向客服反馈。
